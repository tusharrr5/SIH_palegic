# Prototype scope and deferred work

The demonstration is complete as an explicitly labeled historical slick / recorded AIS / training prototype. It is not a live enforcement or navigation system.

| Capability | This build | Deferred / required for operational use |
|---|---|---|
| Historical oil evidence | Three real NOAA/NESDIS composites, 316 original features | More incidents and verified Indian observations |
| SAR detection | Published stored slick geometry, source provenance | Sentinel-1 retrieval, calibration, segmentation, validation and look-alike rejection |
| AIS | Normalization, heuristics, replay, three published recorded passages, synthetic seeds, recorded JSON import | Licensed incident-matched AIS, live ingestion, coverage model and impossible-jump rejection |
| Attribution | Transparent geospatial/temporal/behavior priority | Calibrated source-association validation; human/legal evidentiary process |
| Physics | Equation-based illustrative particle sandbox; real-hindcast requests rejected | Time-matched ERA5/CMEMS/HYCOM forcing, validated forward ensemble or OpenDrift/OpenOil implementation |
| Security | Server RBAC, Argon2, opaque sessions, CSRF Origin gate, expiry and revocation | TLS deployment, managed secrets, recovery/MFA, distributed rate limits, request body cap, tamper-evident external audit and production security review |
| Offline | No external requests required for cached app flows | PostgreSQL, API and frontend must remain running; this is not a serverless/PWA app |
| Administration | Admin creation of authorities, role changes, AIS import, source checksum/audit inspection | Invitation email, self-service recovery, jurisdiction policy and evidence retention |

No microservices, background queues, cloud dependency, deep-learning model, or OpenOil package is bundled. These omissions are intentional to keep the recording reliable and scientific claims supportable. Sample review/export records are demonstration artifacts, not operational decisions.
